# CHICKENS vs TURKEYS — ChatGPT Image Prompts

## How to use
- **One prompt = one image.** Every prompt below is fully self-contained (the style description is repeated inside each one) so you only paste a single block.
- Prompts are in **order of importance** for the build. Do them top to bottom.
- **Attach your concept sheet** (the comic style reference) to each ChatGPT chat as well — the prompts say "match the attached reference" but still work without it.
- For sprite sheets, the prompts ask for a **flat pure green (#00FF00) background**. That is more reliable than "transparent" and I will cut it out for you.
- If an image isn't right, reply in the same chat with a tweak ("make the comb bigger", "more space between parts", "all parts must not overlap") rather than starting over.
- **Generate 2 versions** of the important ones (1–5) and pick the best.
- Upload results back to Claude with the **name given in "Save as"** so I can wire them in. Ask ChatGPT for the highest resolution available, PNG.
